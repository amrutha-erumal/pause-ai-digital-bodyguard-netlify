# Accessibility Checklist

The UI includes semantic buttons and tab roles, visible keyboard focus, ARIA labels/status regions, modal `role="dialog"` + `aria-modal`, Escape-to-close behavior, focus return, and `prefers-reduced-motion` support.

The interface is designed to remain understandable without color alone: threat states include text labels and action language. Screenshot controls work by mouse, keyboard and drag/drop, with clipboard paste supported for convenience.
