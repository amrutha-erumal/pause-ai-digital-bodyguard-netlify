# PromptWars Challenge 3 — Problem Statement

## Track

**AI-Powered Cybersecurity & Digital Safety**

## Exact problem statement

> With the increasing use of digital platforms, phishing, fraudulent websites, malicious messages and identity theft pose significant challenges. Build an intelligent system that can identify suspicious activity and help users make safer decisions online.

## Possible solution directions shown by the challenge

- AI phishing detector
- suspicious URL analyzer
- scam message classifier
- intelligent security assistant that explains potential threats in simple language

## Expected outcome

> A functional prototype that identifies or analyzes a cybersecurity threat and provides actionable security recommendations.

## PAUSE alignment

PAUSE analyzes message text, URLs and screenshots; identifies behavioral/social-engineering signals; uses Google security evidence where configured; explains the threat in simple language; provides an earliest safe breakpoint and concrete next action; and turns the detected tactic into a safe Threat Vaccine training mutation.
