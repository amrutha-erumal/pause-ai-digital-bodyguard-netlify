FUNCTIONAL PROTOTYPE
PROBLEM STATEMENT

With the increasing use of digital platforms, phishing, fraudulent websites, malicious messages and identity theft pose significant challenges. Build an intelligent system that can identify suspicious activity and help users make safer decisions online.

EXPECTED OUTCOME

A functional prototype that identifies or analyzes a cybersecurity threat and provides actionable security recommendations.

01Identify suspicious activity

Behavioral signal engine + Gemini multimodal analysis score urgency, impersonation, credential requests, payment pressure and link risk.

02Analyze phishing & fraud

Accepts messages, URLs and screenshots; never opens the supplied URL from the server.

03Explain in simple language

Threat DNA and “Show Me the Trap” translate technical indicators into human-readable evidence.

04Provide actionable recommendations

Every result ends with a safe next action, earliest safe breakpoint and a trusted-channel alternative.

05Protect user privacy

Privacy Shield masks obvious OTP, card-like and ID-like values before the AI route, with server-only secrets.

06Use Google services meaningfully

Gemini handles multimodal reasoning; Google Search grounding can provide public evidence; Google Safe Browsing checks known URL threats.

CODE QUALITYTestable core + explicit data contracts

Risk logic, parsing and UI orchestration are separated so the critical safety logic can be unit-tested without a browser.

◈
SECURITYServer-only secrets + strict input guards

No Gemini key in the client. Request size limits, MIME allow-listing, same-origin checks, security headers and redacted secrets.

↯
EFFICIENCYCompress first, send once

Screenshot payloads are resized and compressed before upload; requests use timeouts and avoid unnecessary network calls.

✓
TESTINGNode test suite for high-risk logic

Local signal scoring, URL extraction, privacy redaction, image validation and model normalisation have automated tests.

◎
ACCESSIBILITYKeyboard-first + reduced motion

Focus states, labels, live regions, Escape-to-close modals, semantic controls and a reduced-motion mode are built in.
